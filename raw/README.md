# Raw sources

Place curated papers, article exports, research notes, and their attachments here.
Keep existing repository records where they are; there is no need to copy code,
fixtures, plans, or generated arrays into this directory.

Use descriptive filenames, optionally prefixed by the source date. Store related
images beside the source in a matching subdirectory. Once ingested, keep the
source unchanged; add revised editions as separate files.

Ask the agent to ingest a specific path. It will record provenance, summarize the
source, update related topics, and append an entry to the wiki log according to
[AGENTS.md](../AGENTS.md). No external sources have been ingested yet; the initial
[source catalog](../wiki/sources.md) uses repository evidence.
