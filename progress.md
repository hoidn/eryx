## Ground Truth Data

✅ Ground truth data has been generated by running `run_np()` with the `@debug` decorators in place

The data is available in the `logs/` directory but is not included in the source control. The logs follow the naming pattern `logs/eryx.module.function.log` and contain serialized inputs and outputs for testing the PyTorch implementations.
